# shin-summary

実装結果から振り返りレポートや学習コンテンツを作成するワークフロー。

## 概要

| 項目 | 内容 |
|------|------|
| 対象ツール | Claude Code / Codex |
| 用途 | 振り返りレポート、学習コンテンツの作成 |
| 入力 | 計画書ファイル + モード指定 |
| 出力 | レポート/コンテンツファイル |

## 位置づけ

```
planner → tdd/execute → summary ← reviewer
                           ↑
                         今ここ
```

実装完了後のドキュメント化・知識共有フェーズ。

## モード

| モード | 用途 | 対象 |
|--------|------|------|
| `--retrospective` | 振り返りレポート | 自分・チーム |
| `--learning` | 学習コンテンツ | 他者・将来の自分 |
| `--all` | 両方出力（デフォルト） | - |

## 使用例

```bash
# 振り返りレポート
/shin-summary ./docs/{topic}/plan.md --retrospective

# 学習コンテンツ
/shin-summary ./docs/{topic}/plan.md --learning

# 両方出力
/shin-summary ./docs/{topic}/plan.md --all
```

## ワークフロー

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  Collector  │ ──▶ │  Analyzer   │ ──▶ │   Writer    │ ──▶ │   Review    │
│ (情報収集)   │     │ (要点抽出)   │     │ (コンテンツ作成)│     │ (外部レビュー)│
└─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘
```

## 出力形式

### 振り返りレポート

```markdown
# 振り返りレポート: [タスク名]

## 概要
## 実装内容
## 技術的な決定
## 課題と学び
## 改善点
## 所感
```

### 学習コンテンツ

```markdown
# 学習コンテンツ: [トピック名]

## はじめに
## 背景・概要
## 実装解説
## ポイント・Tips
## まとめ
## 参考資料
```

## 出力ファイル

| モード | 出力先 |
|--------|--------|
| retrospective | `./docs/{topic}/retrospective.md` |
| learning | `./docs/{topic}/learning.md` |
