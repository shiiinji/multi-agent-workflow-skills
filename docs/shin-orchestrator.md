# shin-orchestrator

タスクを分析し、最適なワークフローを推奨する上位管理ワークフロー。

## 概要

| 項目 | 内容 |
|------|------|
| 対象ツール | Claude Code / Codex |
| 用途 | ワークフローの選択・進捗管理 |
| 動作モード | 推奨提示（実行は行わない） |

## 位置づけ

```
┌─────────────────────────────────────────────────────────────────┐
│                   orchestrator-workflow                         │
│                   (エントリーポイント)                           │
└──────────────────────────────────────────────────────────────────┘
                           │ 推奨
                           ▼
    ┌──────────────────────────────────────────────────────┐
    │  planner → qa-design → tdd/execute ← reviewer       │
    └──────────────────────────────────────────────────────┘
```

## 機能

1. **タスク分析**: タスクの種類と現在の状況を分析
2. **ワークフロー推奨**: 最適なワークフローを提示
3. **進捗表示**: 全体の進捗状況を可視化
4. **次のステップ提示**: 具体的なコマンドを提示

## 使用例

### 新規タスク

```bash
/shin-orchestrator ユーザー認証機能を追加したい
```

**出力:**
```
## 推奨: planner-workflow

**実行コマンド:**
/shin-planner ユーザー認証機能を追加したい
```

### 進行中のタスク

```bash
/shin-orchestrator ./docs/{topic}/plan.md の次は？
```

**出力:**
```
## 推奨: qa-design-workflow

**実行コマンド:**
/shin-qa-design ./docs/{topic}/plan.md
```

### 問題発生時

```bash
/shin-orchestrator テストが通らない
```

**出力:**
```
## 推奨: reviewer-workflow

**実行コマンド:**
/shin-reviewer "テストが通りません: [エラー内容]"
```

## 状況判定ロジック

```
入力分析
├─ 計画書なし → planner 推奨
├─ 計画書あり
│   ├─ テスト設計書なし → qa-design 推奨（任意）
│   └─ テスト設計書あり or スキップ
│       ├─ TDD 対象あり → tdd 推奨
│       └─ TDD 対象なし → execute 推奨
└─ レビュー依頼 or エラー → reviewer 推奨
```

## 出力形式

```markdown
## 現在の状況

| 項目 | ステータス |
|------|-----------|
| 計画書 | ✅ あり / ❌ なし |
| テスト設計書 | ✅ あり / ❌ なし / ⏭️ スキップ |
| 実装 | ✅ 完了 / 🔄 進行中 / ❌ 未着手 |

## 推奨: [ワークフロー名]

**理由:** [推奨理由]

**実行コマンド:**
\`\`\`bash
/multi-agent-xxx-workflow [引数]
\`\`\`

## 全体の進捗

[1] planner    ✅ 完了
[2] qa-design  ⏭️ スキップ
[3] tdd        🔄 次はここ
[4] execute    ⏳ 待機中

## 他の選択肢
- [代替ワークフロー]
```

## 典型的な使い方

```bash
# 1. タスク開始
/shin-orchestrator [タスク説明]

# 2. 推奨に従って実行
/shin-planner [タスク説明]

# 3. 次のステップを確認
/shin-orchestrator 次は？

# 4. 推奨に従って実行
/shin-qa-design [plan]

# ...繰り返し
```
